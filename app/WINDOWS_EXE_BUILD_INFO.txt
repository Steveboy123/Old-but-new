V2.27 replaces the cloud OpenAI optimizer with self-hosted Ollama for both Rise/Fall
and Multiplier. It supports Advisor, DEMO Auto Lab, DEMO Adaptive validated-preset
selection, and explicit AI Trade mode using only locally validated presets.

AI Trade requires the operator to enable it and type LIVE each time it starts. The
local bot remains the executor, compounding is forced off, AI cannot change stake,
capital or order count, and session loss/profit/trade caps are enforced locally.

No API token, account ID, .env, Web UI secret, external AI key, or runtime trade
data is packaged in this installer payload. Ollama may run on localhost or a user-
configured LAN/self-hosted URL.
